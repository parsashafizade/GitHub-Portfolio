# Prompts — Premium Profile

This file contains practical prompts for customizing the Premium GitHub Profile template.

These prompts help you create stronger profile content, project presentations, and custom SVG components while keeping your information authentic.

---

## 1. Build Your Developer Positioning

Use this before writing your profile.

```

Act as a developer branding advisor.

Help me define my GitHub Profile positioning.

My information:

- Name:
- Current role:
- Experience level:
- Main technologies:
- Strongest projects:
- Interests:
- Career goals:

Create:

- A clear one-line developer identity
- A short professional introduction
- Key focus areas

Avoid generic statements. Make it specific to my actual background.

```

---

## 2. Create a Premium About Section

```

Write an About section for my GitHub Profile README.

Goal:
Create a professional developer introduction that communicates:

- What I build
- What technologies I use
- How I approach software development
- What I am currently improving

Profile information:
[paste your details]

Style:
Professional, concise, engineering-focused.

Avoid exaggerated claims.

```

## Notes

Use AI as a design and writing assistant, not as a replacement for your real experience.

The strongest profiles communicate:

- Real projects
- Clear engineering interests
- Honest technical skills
- Consistent personal identity
