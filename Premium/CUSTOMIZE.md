# Customize — Premium Profile

This guide explains how to adapt the Premium GitHub Profile template to your own developer identity.

Premium is designed for developers who want a stronger portfolio presentation by combining clear content, project highlights, activity data, and custom visuals.

---

## 1. Define Your Developer Identity

Start by updating the sections that explain who you are.

Update:

- Name
- Role
- Professional introduction
- Development focus
- Career direction

A strong profile should answer:

- What do you build?
- What technologies do you use?
- What type of problems do you enjoy solving?

Avoid broad statements that do not describe your actual work.

---

## 2. Customize Focus Areas

Find:

```

## What I'm focused on

```

Update the focus sections based on your real interests.

Examples:

- Mobile Development
- Backend Engineering
- AI Systems
- Cloud Infrastructure
- Open Source
- Product Development

Choose areas that represent your current direction.

---

## 3. Select Projects Carefully

The project section is one of the most important parts of this template.

Prioritize projects that show:

- Technical depth
- Problem solving
- Good engineering practices
- Meaningful implementation

For each project card, consider including:

- Project name
- Purpose
- Technologies
- Key technical decisions
- Repository link

Do not include projects only because they exist. Include projects that represent your capabilities.

---

## 4. Customize SVG Assets

Assets are located in:

```

assets/

```

Main components:

```

hero.svg
focus-loop.svg
activity/
projects/
section-divider.svg

```

You can modify:

- Text
- Colors
- Typography
- Layout
- Visual elements

Keep the SVG files:

- Lightweight
- Editable
- Compatible with GitHub README rendering

---

## 5. Project Card Generation

Premium supports generated project cards.

Related scripts:

```

scripts/generate-project-cards.py

```

Use automation when you want project sections to update automatically.

Before using automation, review:

- Which repositories are included
- How projects are selected
- Generated output quality

Automated content should still represent your best work.

---

## 6. Activity Sections

Premium includes GitHub activity visuals:

```

assets/activity/

```

These sections can show:

- Contribution activity
- Language usage
- GitHub statistics

Use them only if they add useful context.

A profile should not become only a collection of metrics.

---

## 7. Using AI for Customization

AI can help with:

- Writing profile sections
- Improving project descriptions
- Creating SVG variations
- Reviewing your portfolio structure

When requesting changes, provide:

- Your real background
- Your target audience
- Your preferred visual style
- Existing SVG code when modifying assets

Ask AI to preserve:

- SVG compatibility
- Lightweight structure
- Professional tone

---

## Final Checklist

Before publishing:

- [ ] Profile represents your real experience
- [ ] Featured projects are meaningful
- [ ] Text is specific and authentic
- [ ] SVG assets load correctly
- [ ] Automated sections work correctly
- [ ] Design supports your portfolio

The Premium style should make your work easier to understand, not hide it behind visuals.
