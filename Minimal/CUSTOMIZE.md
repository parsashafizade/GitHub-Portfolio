# Customize — Minimal Profile

This guide explains how to adapt the Minimal GitHub Profile README to your own developer identity.

The goal of this template is to keep your profile clear, professional, and focused on your actual work.

---

## 1. Update Personal Information

Open:
```

README.md

```

Replace:

- Name
- Role / Title
- Introduction
- Background
- Social links

Keep your description specific.

Example:

Instead of:

```

I love technology and coding.

```

Prefer:

```

Mobile Developer focused on Flutter, product development, and building practical applications.

```

---

## 2. Customize Your Tech Stack

Find:

```

## Tech Stack

```

Update technologies based on your real experience.

Avoid listing every technology you have tried.

Focus on:

- Main development stack
- Tools you actively use
- Technologies relevant to your projects

---

## 3. Update Projects

The project section should highlight your strongest work.

For each project, consider:

- What problem does it solve?
- What technologies were used?
- What did you build?
- What makes it interesting?

Quality is more important than the number of projects.

---

## 4. Customize SVG Assets

Assets are located in:

```

assets/

```

Main files:

```

hero-accent.svg
metric.svg
github-snapshot.svg
section-divider.svg

```

You can:

- Edit text inside SVG files
- Change colors
- Adjust spacing
- Replace visual elements

Keep SVGs lightweight because GitHub Profiles should load quickly.

---

## 5. Using AI for Customization

AI can help you modify SVGs or improve content.

Provide:

- Your role
- Your technologies
- Your projects
- Desired visual style

Ask AI to keep:

- Pure SVG output
- GitHub compatibility
- Responsive layout
- Lightweight structure

---

## 6. Optional Automation

This template includes:

```

scripts/

```

These scripts can generate dynamic sections such as GitHub activity data.

Automation is optional. A static profile is completely valid.

---

## Final Checklist

Before publishing:

- [ ] All information is accurate
- [ ] Links work correctly
- [ ] Projects represent your real work
- [ ] SVG files load correctly
- [ ] Profile is readable on GitHub
- [ ] Design supports your content, not the opposite

A good GitHub Profile is not the most complex one; it is the one that clearly communicates who you are and what you build.
