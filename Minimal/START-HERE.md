# Start Here — Minimal Profile

This template is designed for developers who want a clean, professional GitHub Profile README with a focus on clarity, projects, and engineering identity.

## Setup

### 1. Create your GitHub Profile Repository

Create a public repository with the exact name:

```

your-username/your-username

```

GitHub will use the `README.md` file from this repository as your profile page.

---

### 2. Copy the Template

Copy:

```

Minimal/README.md

```

into your profile repository.

---

### 3. Customize Your Information

Update:

- Name and introduction
- Main role
- Skills and technologies
- Projects
- Background
- Social links

Look for sections marked with:

```

<!-- EDIT -->

```

These are the main areas you need to change.

---

### 4. Add Assets

Copy the required files from:

```

Minimal/assets/

```

to your profile repository.

Keep the folder structure unchanged.

---

### 5. Generate Optional Data

If you want automatic GitHub activity updates, use:

```

Minimal/scripts/

```

and follow the instructions inside `CUSTOMIZE.md`.

---

## Next Steps

- Read `CUSTOMIZE.md` for personalization.
- Read `PROMPTS.md` for AI-assisted content and SVG creation.
- Preview your profile before publishing.

The goal is not to make your profile visually complex; it is to present your work clearly and professionally.
