# Prompts — Minimal Profile

This file contains practical prompts for customizing the Minimal GitHub Profile template with AI assistance.

Use these prompts as a starting point and provide your real information, projects, and goals.

---

## 1. Create Profile Content

Use this when you do not have a GitHub Profile description yet.

```

Act as a developer branding advisor.

Help me create a professional GitHub Profile README introduction.

My information:

- Name:
- Current role:
- Main technologies:
- Projects:
- Interests:
- Career goal:

Create:

- A short professional introduction
- A clear developer positioning statement
- A concise list of technical interests

Avoid generic phrases. Keep it authentic and suitable for recruiters and developers.

```

---

## 2. Improve Existing README Text

```

Review my GitHub Profile README as a technical recruiter and developer.

Analyze:

- Clarity of my positioning
- Professional impression
- Technical credibility
- Unnecessary sections
- Missing information

Suggest improvements while keeping my real background unchanged.

README:
[paste README]

```

## 3. Generate a Hero SVG

```

Create a lightweight SVG hero illustration for a GitHub Profile README.

Requirements:

- Clean minimal developer style
- Professional portfolio feeling
- Lightweight SVG code
- GitHub README compatible
- No raster images
- Responsive width

Developer profile:
[describe yourself]

Style:
Minimal, modern, clean, engineering-focused.

Return only SVG code.

```

## 6. Final Profile Review

```

Review my GitHub Profile README before publishing.

Evaluate:

- Professional appearance
- Recruiter readability
- Developer credibility
- Technical accuracy
- Balance between design and content

Give specific actionable improvements.

README:
[paste README]

```

---

## Notes

AI can help generate structure, wording, and visual ideas, but the final profile should always represent your real skills, experience, and projects.
