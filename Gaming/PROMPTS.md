# Prompts — Gaming Profile

This file contains practical prompts for customizing the Gaming GitHub Profile template.

The goal is to create a unique developer profile experience while keeping the content accurate, professional, and connected to real engineering work.

---

Use this when you need to define the information shown in your profile.

* Projects:

* Career goals:

* Developer identity
