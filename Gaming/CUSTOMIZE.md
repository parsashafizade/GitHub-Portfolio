# Customize — Gaming Profile

This guide explains how to adapt the Gaming GitHub Profile README to your own developer identity.

The Gaming style focuses on creating a memorable visual experience using HUD-inspired layouts, custom SVG components, and developer-focused sections.

The visual design should support your technical profile, not replace it.

---

## 1. Customize Your Developer Identity

Start by updating the main information:

- Name
- Developer role
- Technologies
- Current focus
- Links

The profile should clearly communicate:

- Who you are
- What you build
- What technologies you use

Avoid adding fictional levels, achievements, or skills.

---

## 2. Customize the Profile Components

The main visual sections are located in:

```

assets/

```

Main files:

```

hero.svg
player-card.svg
project-select.svg
contribution-map.svg

```

Each component represents a different part of your developer profile.

You can modify:

- Text
- Colors
- Icons
- Labels
- Layout
- Visual effects

Keep the original SVG structure when possible to maintain GitHub compatibility.

---

## 3. Customize the Visual Theme

The Gaming style can be adapted to different directions:

Examples:

- Cyber / futuristic
- Terminal-inspired
- Sci-fi engineering dashboard
- Retro developer interface
- Minimal HUD

When changing the style, keep:

- Good readability
- Clear information hierarchy
- Fast loading

Avoid excessive effects that make the profile difficult to read.

---

## 4. Update Projects

Project sections should represent your strongest work.

For each project, include:

- Project name
- Purpose
- Technologies
- Repository link
- Technical highlights

Think of projects as "missions", but keep the information technically accurate.

Good:

```

Built a Flutter application with offline storage and API integration.

```

Avoid:

```

Level 99 app that changed the world.

```

---

## 5. Generated Assets

Gaming includes scripts:

```

scripts/

```

These can help generate profile-related assets and update sections.

Before running scripts:

- Review generated output
- Confirm your repository data is correct
- Check that only appropriate projects are displayed

Automation should improve maintenance, not add unnecessary complexity.

---

## 6. Using AI for Customization

AI can help you:

- Rewrite profile sections
- Design new SVG components
- Create visual variations
- Review the final profile

When requesting changes, provide:

- Your developer background
- Your target audience
- Desired visual direction
- Existing SVG code

Ask AI to preserve:

- Pure SVG output
- GitHub README compatibility
- Lightweight files
- Editable structure

---

## Final Checklist

Before publishing:

- [ ] Profile information is accurate
- [ ] Projects represent real work
- [ ] SVG files render correctly
- [ ] Text remains readable
- [ ] Visual effects do not hide technical content
- [ ] Links work correctly

A creative GitHub Profile works best when the presentation is memorable and the engineering content remains clear.
